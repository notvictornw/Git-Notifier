# Security Policy

We take security seriously and want to keep this integration safe for everyone.

---

## Supported Versions

Only the latest release of the GitHub to Discord Webhook server receives security updates.

| Version | Supported |
| :--- | :--- |
| >= 1.0.0 | Yes |

---

## Reporting a Vulnerability

Please do not open a public issue for security bugs. Instead, email reports to the maintainers or use GitHub's private security reporting feature.

When reporting, please include:
1. A detailed description of the vulnerability and its potential impact.
2. Step-by-step instructions or proof-of-concept code to reproduce the issue.
3. Any mitigations or fixes you suggest.

We will acknowledge receipt of your report within 48 hours and work with you to patch and release a fix quickly.
