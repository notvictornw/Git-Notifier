# Support

## Onde pedir ajuda

- **Dúvidas/uso:** abra uma [issue](https://github.com/notvictornw/Git-Notifier/issues/new/choose) com contexto.
- **Bugs:** use o template [Bug report](https://github.com/notvictornw/Git-Notifier/issues/new?template=bug_report.yml).
- **Vulnerabilidades:** use o [reporte privado](https://github.com/notvictornw/Git-Notifier/security/advisories/new). Não use issue pública.

## Antes de abrir issue

- Consulte [README](./README.md) e [docs/](./docs/).
- Verifique [Troubleshooting](./docs/troubleshooting.md).
- Remova segredos de logs/configurações.
- Inclua versão/commit, runtime, passos de reprodução e logs relevantes.
